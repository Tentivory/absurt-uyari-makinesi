# ABSÜRT UYARI MAKİNESİ

## Resmi Tanım

Bu sistem, insanlığın en büyük tehdidi olan "günlük sıradan eylemler"e karşı geliştirilmiş, aşırı ciddi, bilimsel temelli (cidden) ve tamamen gereksiz bir uyarı üretme platformudur.

**Ne yapar?**
- "Çay demle" dediğinizde size üçüncü dünya savaşı senaryosu sunar.
- "Kapıyı aç" dediğinizde evrenin sonunu hesaplar.
- Her şeyi nükleer seviyede abartır.

## Kullanım

```bash
python3 uyari_makinesi.py
```

Sonra bir eylem yazın. Sistem size hayatınızı kurtaracak (veya mahvedecek) uyarıyı verecektir.

**Örnek:**
```
Eylem: Su iç
UYARI: DİKKAT! Su içmek, vücudunuzdaki hidrojen atomlarının potansiyel füzyon reaksiyonuna yol açabilir. Lütfen 47 katmanlı koruyucu ekipman giyin ve en yakın uzay ajansına haber verin. Bu işlem onaylanmıştır. Cidden.
```
